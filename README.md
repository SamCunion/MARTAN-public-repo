# MARTAN

### <i>Mesoscale And Radar Tornado Analysis Network</i>

A convolutional neural network that analyses raw NEXRAD radar data, and predicts the likelihood of an ongoing tornado. Also attempts to analyse the latest HRRR to form a prediction on likely tornado maximum intensity.

Trained on the TorNet NEXRAD radar imagery dataset at https://github.com/mit-ll/tornet .

This repo contains a selection of the source code that includes model definitions, training, evaluation, and dataset modification. Not all source code is included in this repo. 

A research paper was produced on MARTAN, which is also accessible in this repo.
